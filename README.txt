LAST CITY: AFTERFALL — 3D browser prototype

Open index.html in a modern desktop browser with an internet connection.
If your browser blocks module imports on file://, upload index.html to GitHub Pages.

Controls: WASD move, mouse look, click fire, R reload, Shift sprint, Space jump, Esc pause.

This is a procedural Three.js prototype, NOT GTA-quality photorealism. GTA-level fidelity requires professional 3D assets, animation, audio, lighting, engine and extensive production work.

Uses Three.js 0.170.0 via jsDelivr CDN. Internet required.
